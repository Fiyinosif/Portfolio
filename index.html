AGORA — PROJECT READMEOPEN +

Overview

Agora is a thread-based discussion platform built for CMPS 285. Users create public or private discussions, reply in threaded conversations, follow discussions and users, and discover content through tags, custom tags, and a trending sidebar.

Features

  • Public & private discussions with threaded replies (self-referencing discussion model)
  • Tag filtering, custom tags, search, and a trending discussions sidebar
  • Follows for users and discussions, invites, and bans
  • Role-based permissions for members, admins, and owners

Tech Stack

  • Frontend: React + TypeScript + Mantine UI
  • Backend: C# / ASP.NET Core REST API (Swagger documented)
  • Database: SQL Server — 10 tables, self-referencing discussions table for threading

Roles & Permissions

RoleCan do
MemberPost, reply, follow, join discussions
AdminModerate content, manage members, invites & bans
OwnerFull control, manage admins and discussion settings

Architecture

React / TypeScript (Mantine UI) → ASP.NET Core REST API (Swagger) → SQL Server (10 tables). Threading is modelled with a self-referencing discussions table, so replies nest under a parent discussion.

Getting Started

  • Run the SQL Server database scripts to create the 10-table schema
  • Start the ASP.NET Core API and open Swagger to explore endpoints
  • Install frontend dependencies and start the React app, pointing it at the API base URL

Team Lead: Fiyinfoluwa Osifala — with Rhett Hill, Ashante Harris, and David Bestman. Built for a course client (the CMPS 285 instructor).
